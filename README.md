# Elite Games - Frontend

## Descripción

El frontend de Elite Games es el componente visual de la plataforma de venta de videojuegos digitales. Permite a los usuarios interactuar con el sistema mediante interfaces web diseñadas para facilitar la navegación, la consulta del catálogo y la gestión de sus compras.

## Funcionalidades principales

- Visualización del catálogo de videojuegos.
- Interfaz de inicio de sesión.
- Interfaces para la gestión del perfil de usuario.
- Gestión visual del carrito de compras.
- Consulta y visualización de pedidos.
- Administración de productos y usuarios mediante interfaces administrativas.
- Interfaces para la gestión de inventario y pedidos de proveedores.
- Comunicación con el backend mediante solicitudes a la API.

## Tecnologías

- **HTML:** estructura de las páginas web.
- **CSS:** estilos y diseño de las interfaces.
- **JavaScript:** interactividad y lógica del lado del cliente.

## Estructura del proyecto

El proyecto se organiza en carpetas y archivos que separan las interfaces por módulos, los estilos, los scripts y los recursos compartidos.

## Instalación y ejecución

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador web o utilizar un servidor local.
4. Configurar las direcciones de la API del backend según el entorno de ejecución.

## Integración con el backend

El frontend se comunica con el backend de Elite Games para enviar solicitudes y recibir información relacionada con usuarios, videojuegos, carritos, pedidos y demás funcionalidades disponibles.
